# Ceratek 车床触摸屏固件：一步一步操作指南（Windows 10）

这份指南假设你**不懂驱动、不懂固件**，照着做就行。每一步都写了"应该看到什么"和"不对怎么办"。
遇到任何报错，把黑色窗口里**最后 50 行**复制给 Claude，不用自己判断。

整个过程分四段：

1. 在电脑上装工具、编译固件（第 1–4 步，不碰板子）
2. 烧录，点亮屏幕，检查显示和触摸（第 5–8 步）。注意：现在的包默认 `allow_motion: true`，烧录后屏幕就能让电机动
3. 打开运动功能，在台架上做安全测试（第 9–11 步）
4. 随时可以退回原来的固件（第 12 步）

---

## 0. 开始前准备

- 一台 Windows 10 电脑，能上网。
- 主控板 MKS DLC32、TS35 屏、12 V 电源、USB 线、限位开关、急停开关（接在 "X" 限位插座上）。
- 屏幕排线：**EXP1 对 EXP1、EXP2 对 EXP2**。插拔排线前先拔 12 V 电源。2026-11-21 实测：屏幕背面朝上、蜂鸣器在**右下角**时，屏幕**上面**的插座接主控板**靠外边**（离 ESP32 远）的插座，**下面**的插座接**紧挨 ESP32** 的插座。插反了屏幕全黑，蜂鸣器不一定响。
- 撕掉屏幕上的保护膜（不撕也能用，但触摸会不准）。
- 第 1–8 步**不用接电机**；接了也没关系，这几步固件不会让电机动。

## 1. 安装三样东西（只做一次）

### 1.1 Python

1. 打开 <https://www.python.org/downloads/>，点黄色的 "Download Python 3.x" 按钮。
2. 运行下载的安装程序。**第一页最下面一定要勾上 "Add python.exe to PATH"**，然后点 "Install Now"。

### 1.2 Git

1. 打开 <https://git-scm.com/download/win>，下载 "64-bit Git for Windows Setup"。
2. 运行安装程序，**所有选项都用默认值**，一路点 "Next"，最后 "Install"。

### 1.3 主控板的 USB 驱动（CH340）

主控板上的 USB 芯片叫 CH340。Windows 10 一般会自动装好它的驱动，先检查一下：

1. 接上**12 V 电源**（这块板子只插 USB 不会工作，电脑也看不到它），再插 USB 线。
2. 在开始菜单上**点右键**，选"设备管理器"。
3. 展开"端口 (COM 和 LPT)"。
   - 如果看到 **"USB-SERIAL CH340 (COM5)"** 这样的一行：驱动已经好了。**记下括号里的 COM 号**，后面会用到。
   - 如果没有"端口"这一项，或者在"其他设备"里有一个带黄色感叹号的"USB2.0-Serial"：需要装驱动。到 CH340 芯片厂家沁恒的官网 <https://www.wch.cn/downloads/CH341SER_EXE.html> 下载 `CH341SER.EXE`，运行后点"安装"，然后拔掉 USB 再插上，回到第 3 步检查。

## 2. 放好文件夹，下载 FluidNC（只做一次，要联网）

1. 把 `ceratek-screen-firmware.zip` 解压到你的项目文件夹，例如：

   `J:\deepseekharness\workspace\deepseek-harness\default-workspace\fluidnc_modifedversion\ceratek-screen-firmware`

   放在哪里都可以，**路径里最好不要有中文和空格**。

2. **编译用的文件会放在另一个短文件夹里：同一个盘的根目录下的 `ctk`**，比如项目在 J 盘，就是 `J:\ctk`。脚本会自动创建它。
   - 原因：FluidNC 编译时会在里面再建很深的文件夹，加上你项目文件夹本身的长路径，会超过 Windows 的路径长度上限（260 个字符），编译器就会报莫名其妙的错。
   - 这个文件夹大约占 **2 GB**（编译工具、FluidNC 源码）。项目结束后可以整个删掉。
   - 编译好的固件仍然会放回你的项目文件夹里的 `output\`。
   - 如果 J 盘根目录不能写、或者想换个地方，在黑色窗口里先输入 `set CERATEK_WORK=C:\ctk`，再运行后面的命令（每次新开黑色窗口都要先输入一次）。

3. 打开 `ceratek-screen-firmware` 这个文件夹，**点一下窗口上方的地址栏**，输入 `cmd`，按回车。会弹出一个黑色窗口（命令提示符），它已经在这个文件夹里了。后面所有命令都在这个黑色窗口里输入。

4. 输入下面的命令，按回车：

   ```
   lathe setup
   ```

**应该看到**：最后一行是 `==> Setup done. Next: lathe build`。这一步会装编译工具 PlatformIO，并下载 FluidNC v4.1.1 源码，大约 3–10 分钟。

**如果提示找不到 Python 或 Git**：说明第 1 步没装好，或者装 Python 时没勾 "Add python.exe to PATH"。重新运行 Python 安装程序，选 "Modify" 或重装并勾上那一项。装完以后**关掉黑色窗口，重新打开一个**再试。

## 3. 编译固件

```
lathe build
```

- **第一次**会自动下载 ESP32 的编译工具，可能要 10–20 分钟，期间会滚很多字，这是正常的。
- **应该看到**：最后几行有 `SUCCESS`，然后是 `==> Built: output\firmware-ceratek.bin`。
- **如果最后出现 `ERROR`、`FAILED` 或 `error:`**：这是我（Claude）写的代码第一次在真正的 ESP32 编译器上编译，可能有小错误。把最后 50 行复制给 Claude（在黑色窗口里用鼠标选中，按回车就复制了），修好后从这一步重来。这一步不碰板子，不会有任何影响。

（电脑上的逻辑测试我已经跑过，40 个全部通过，Windows 上不用再跑。）

## 4. 关掉占用串口的程序

烧录之前，关掉其他可能在用主控板串口的程序：`python -m lathe monitor`、Arduino、串口助手、LaserGRBL 等。

## 5. 烧录固件

1. 接好 12 V 电源（板子上 `VIN`、`5V`、`3V3` 三个灯都要亮），再接 USB。
2. 在黑色窗口里输入：

   ```
   lathe flash
   ```

   这一步会：写入新固件，再写入配置文件 `config\config_screen.yaml`。速度设成了 115200（之前备份时发现这根 USB 线速度更快会丢数据），所以需要几分钟。

**应该看到**：两次 `SUCCESS`，最后一行 `==> Done. Unplug the 12 V supply ...`。

**如果提示找不到串口，或电脑上有好几个串口**：用第 1.3 步记下的 COM 号，这样运行：

```
lathe flash -Port COM5
```

（把 `COM5` 换成你的。）后面所有带串口的命令都可以加 `-Port COM5`。

**如果提示 `Failed to connect to ESP32`**：拔掉 USB 再插上，重试一次。

## 6. 重新上电，看屏幕

拔掉 12 V 电源，等 5 秒，再插上。

**应该看到的顺序**：

1. 屏幕亮起，显示 `Ceratek tube lathe`、`Starting...`。
2. 第一次会进入**触摸校准**：屏幕角上依次出现箭头，用指甲或触控笔**用力点箭头尖**，一共 4 个角。
3. 进入主页面：
   - 顶部状态栏左边是红色的 `Alarm`（正常：FluidNC 开机要求先回零），旁边是 X、Y、Z 坐标和 `Inputs: none`。
   - 右上角有一个每秒闪一下的小白点，说明屏幕程序在运行。
   - 中间一行灰字 `Free memory ... bytes`，**请把这个数字记下来告诉 Claude**。
   - 一行黄字 `Motion is off: allow_motion is false in config.yaml.`（正常，这一阶段故意不让机器动）。
   - 下面三个按钮：`Start new tube`（开始车一根管）和 `Manual`（手动控制）现在是灰色、点不了；`Calibrate`（重新校准触摸）可以点。

**如果屏幕不对，按下表处理。** 每次改完配置都运行 `lathe config`，然后拔 12 V 重新上电：

| 看到的现象 | 改哪里（文件 `config\config_screen.yaml`） |
|---|---|
| 屏幕完全黑，连背光都不亮 | 先断电，在**主控板那一头**把两根排线互换（2026-11-21 实测就是这个原因）；还不行，把 `backlight_pin: gpio.5:low` 改成 `backlight_pin: gpio.5` 试试 |
| 背光亮了，但全白或全黑，没有字 | `lcd_spi_hz: 40000000` 改成 `20000000`；还不行就断电，把排线拔下重新插紧 |
| 有字，但黑白颠倒 | `invert_colors: false` 改成 `true` |
| 红色显示成蓝色 | `swap_red_blue: false` 改成 `true` |
| 画面方向不对 / 倒过来 | `rotation: 1` 改成 `3`（或 `0`、`2`），改完点 `Calibrate` 重新校准 |
| 点按钮的位置不准 | 点 `Calibrate` 重新校准；或者开机时一直按着屏幕，也会进入校准 |
| 屏幕黑、蜂鸣器嘀嗒响 | 排线插反了：断电，EXP1 对 EXP1、EXP2 对 EXP2 |

**怎么改配置**：在文件夹里进入 `config`，在 `config_screen.yaml` 上点右键 →"打开方式"→"记事本"。只改冒号后面的值，**不要动行首的空格**，然后保存（Ctrl+S）。

## 9. 打开运动功能

> **2026-11-21 起，固件包里的 `config_screen.yaml` 默认就是 `allow_motion: true`**（台架测试 S1–S3 已经通过）。烧录后屏幕就能控制电机，不用再手动改。想让屏幕不能动机器，就把它改成 `false`。

**只有第 8 步全部通过才做这一步。**

1. 用记事本打开 `config\config_screen.yaml`，把 `allow_motion: false` 改成 `allow_motion: true`，保存。
2. 运行 `lathe config`，然后拔 12 V 重新上电。
3. 主页面的黄字消失，`Start new tube` 和 `Manual` 变成可以点。

从这一步起，**机器完全靠屏幕控制，不需要接电脑**，USB 线可以拔掉。电脑只在以后要更新固件或改配置时才用。

### 屏幕上能做的事

| 页面 | 能做什么 |
|---|---|
| 主页面 | `Start new tube`：引导车一根管（回零 → 输入尺寸 → 对刀 → 一刀一刀车 → 测量 → 汇总）；`Manual`：进入手动页面；`Calibrate`：重新校准触摸 |
| 手动页面（`Manual`） | `Home`：回零；`Recover`：急停或报警之后恢复（之后要再回零）；选步长 0.1 / 1 / 5 / 10 mm，然后 `Y to tube` / `Y away` / `Z along` / `Z back` 移动刀具；`Turn +1 rev` / `Turn -1 rev`：让管子转一圈；`Back`：回主页面 |
| 任何时候 | 机器在动时右上角有 `Pause` / `Resume`（暂停 / 继续，**不是急停**）；红色急停开关随时有效 |

规则和以前电脑上的程序一样：急停或报警之后，必须先 `Recover`、再 `Home`，才能再车削；手动页面上回零过的话，开始车管时不会再要求回零。

## 10. 台架测试：按小组方案走一遍（2026-11-24 起）

**接线**（插拔前先拔 12 V）：
- 横向丝杆的电机（刀靠近 / 离开管子）→ `Y1-Motor`；竖向丝杆的电机 C（刀沿管子走）→ `Z-Motor`。
- 开关 B（横向起点）→ Y 限位插座；开关 C（竖向起点）→ Z 限位插座；开关 A（竖向另一头）→ X 限位插座。
- 起点（左下角）= B、C 都被碰到的位置。管子旋转轴以后再加。

**第三轴开关 `X: ON / X: OFF`（顶部状态栏，2026-11-25 起）：** 开机默认 `X: OFF`。
- 没有流程在跑时按 `X: ON`：管子马上按设置的转速一直转；按 `X: OFF` 停。控制器在报警状态（开机后还没 Locate / Home）时转不了，屏幕会提示先 Locate。
- 机器要做别的动作（Locate、回零、手动移动、车管子）时，管子先停；做完后如果还是 `X: ON`，管子再转起来。
- 车管子流程中按它：决定切削时管子转不转。

**`Speeds`（主页面 Locate 旁边）：** 改两个速度，存在板子里，断电不丢：
1. 管子转速（X），rev/min，最大是 config 里 X 的 `max_rate_mm_per_min`（2026-11-26 起是 200）。
2. Y、Z 的移动速度，mm/min（回零以外的移动、Locate、手动移动），最大 960（= 电机 120 转/分，导程 8 mm）。默认仍是 120 mm/min。
车管子时转速输入框的默认值也用这里设的转速。**注意：** 板子上一旦在这页存过数，就一直用存的数，config 里的 `tube_rpm: 200` 不起作用。要用 200，就在这页输入一次 200。

**`Test X motor`（主页面右边，地图下面）：** 单独测试 X 电机。开机报警状态下也能用（会先解除控制器的锁定；Y、Z 仍然要 Locate 才能车管子）。
- 先选速度 2 / 10 / 30 / 60 rev/min。
- `+1 turn` / `-1 turn`：转一圈，看轴是不是正好转了一圈；记录里写出控制器数到了多少圈。
- `Run +` / `Run -`：一直转，`Stop` 停。离开这一页（`Back` 或 `Main`）也会停。
- 判断：连 2 rev/min 都只抖不转 → 电机两组线圈接错（调换插头中间两根线）；慢的能转、快了抖 → 速度太高或驱动电流太小；完全没反应 → 查 `X-Motor` 插头和驱动模块。

**先试手动页面：** 点 `Manual` → `Home`，横向会先退到 B，竖向再退到 C。然后选步长，试 `Y to tube` / `Y away` / `Z along` / `Z back`，确认方向对（`Y to tube` 应该往管子走，`Z along` 应该往 A 走）。方向反了告诉 Claude 改配置。

**先定位（每次开机后做一次）：** 主页面点 `Locate`。机器先退到 B、再沿管子退到 C（回零），然后刀先往管子方向挪 5 mm（避开 B 开关），再沿管子一直走到碰到 A，量出 C 到 A 的距离，然后沿管子退到坐标 0、刀再退到坐标 0，到 0 就停（路上碰到开关也停，但会报警告：说明丢步了）。定位之前，位置图上的刀显示在正中间，标着 `not located`；`Start new tube` 是灰的，点不了。

**完整走一遍（2026-11-24 小组流程）：** 先 `Locate`，然后点 `Start new tube`。之后每一步屏幕上都有 `OK` 和 `Return` 两个按钮。
1. **找深度**：先用数字键盘输入每轮往管子进多少（0.01–10 mm），框里先显示上次用的值，直接 `OK` 就用它。然后刀从左下角往右（往管子）走一步停下。位置对了按 `OK`；不对按 `Return`，再往右走一步，一直重复。中途按 `Settings` 也能改步长。
2. **测长度**：刀沿管子慢慢往 A 走。到了想要的长度按 `OK`；不对按 `Return`，回到长度起点重新测。碰到 A 开关就自动停，长度算到 A 前面 1 mm（`switch_a_margin_mm`），这样车削时不会再碰到 A。
3. **设置车削参数**：长度确定后机器停下，屏幕用数字键盘依次问转速（rev/min）和走刀速度（mm/min），默认是配置里的值；最后显示汇总，`OK` 开始车，`Return` 重新改。
4. **车削**：管子转起来（旋转轴以后接），刀在找好的深度上，从长度起点沿管子车到长度终点。
5. **回起点**：刀先往左退到 0，再沿管子退到 0。坐标到 0 就算回到起点；路上碰到开关也会停，并报警告（说明丢步了）。
6. 屏幕显示最终的深度和长度。

**蜂鸣器和警告（2026-11-26 起）：**
- 计划内碰到开关，只在屏幕上显示一条消息，不响：回零时碰 B、C；Locate 和测长度时碰 A。
- 不该碰的时候碰到开关，屏幕上出现红色 `WARNING:`，蜂鸣器响 3 声。比如找深度、车削、回起点、手动移动、管子自己转（`X: ON`）的时候。回零失败也算。
- 自己按 `Main`，或者回零时按 `Stop`，都不算警告。
- 按屏幕按钮不再“嘀”一声。
- 第一次用时检查一次：回零后机器是 `Idle`，用手按一下开关 B。屏幕应该出红色 WARNING，并响 3 声。
  - 一直响：把 `beeper_pin` 改成 `I2SO.7:low`。
  - 不响：改成 `NO_PIN`，并告诉组里。

**要改的数字**（在 `config\config_screen.yaml` 里，改完运行 `lathe config -Port COM7`）：
- `depth_step_mm`：第一次问步长时框里显示的值（现在是 1.0）。之后显示上次用的步长。
- `cut_feed_mm_per_min`：找深度、测长度和车削的速度。
- `tube_rpm`：车削时管子的转速（现在是 200；Speeds 页存过数的话用存的数）。
- `switch_a_margin_mm`：长度碰到 A 时，车削停在 A 前面多少 mm（现在是 1.0）。
- `y:` 和 `z:` 下面的 `steps_per_mm`（丝杆导程）和 `max_travel_mm`（能走多远）。

## 12. 随时退回原来的固件

任何时候觉得不对，都可以一条命令退回 11 月 14 日测过的 FluidNC v4.1.1（带 Wi-Fi）和原来的配置：

```
lathe restore
```

完成后拔 12 V 重新上电。屏幕会像以前一样黑着，电脑上的 `py -m lathe run` 照常可用。

**注意**：原版 FluidNC 不认识 `lathe_screen:` 这一段配置，会直接报配置错误锁住机器。所以退回时一定要用 `restore`，它会同时写回原来的配置，不要只换固件。

---

## 13. 想保留 Wi-Fi 网页的话

默认的固件**没有 Wi-Fi**：内存更宽裕，也不会再开那个用默认密码的 `FluidNC` 热点。
如果想同时保留 Wi-Fi 网页：

```
lathe flash wifi
```

- 这个版本用的是板子完整的 8 MB 闪存布局，因为屏幕代码加 Wi-Fi 放不进原来的 4 MB 布局。
- 以后改配置用 `lathe config wifi`。
- 想换回无 Wi-Fi 版本，运行 `lathe flash` 即可。
- Wi-Fi 版本开机会开一个名叫 `FluidNC` 的热点，密码是默认的。展示时附近的人都能连上来控制机器，**用之前一定要改密码**（问 Claude 怎么改）。

## 附：Mac 或 Linux

如果组里有人用 Mac 或 Linux，命令完全一样，只是写法换成 `./lathe.sh`，串口用环境变量指定：

```bash
./lathe.sh setup
./lathe.sh build
./lathe.sh flash          # 或 PORT=/dev/cu.usbserial-130 ./lathe.sh flash
./lathe.sh config
./lathe.sh monitor
./lathe.sh restore
./lathe.sh test           # 电脑上的逻辑测试，需要 g++ 或 clang++
```

Mac 上缺 git 或 python3 时，在终端里运行 `xcode-select --install` 安装。
